01 The product, before

Sideout — record a volleyball rep, get a breakdown where every note points at the exact frame, run the one priority fix that buys the most, and watch a rolling rating move across six skills. Built for a player reviewing their own film on a phone. It already worked and shipped; the mission was to make what existed impeccable, not to redesign it. The design tokens (ten colors, three fonts) were law.

What the audit found

Cross-cutting gaps
  • Token drift — hardcoded gold in cursor-glow/score-ring, off-palette navy in clip-viewer, the whole palette hardcoded on the share-card canvas, an eleventh color in the sheen gradient.
  • Accessibility — SVG data-visuals with no name, progress bars without role=progressbar, streaming surfaces with no live region, single-select modeled as toggles instead of a radiogroup, colour-only state.
  • Touch targets — Log-in, tab bar, chips, several controls under 44px.
  • Focus — dropped on step transitions and after submit; no skip link before fixed headers.
Structure & states
  • No boundaries — no error.tsx, no not-found, only the root layout set a title.
  • Silent failures — Supabase fetch errors coerced to empty state via ?? [] on five routes.
  • No mobile nav — landing section links unreachable below 768px.
  • Reduced-motion — several rAF/JS effects never re-checked matchMedia; the clip auto-advance ignored it.
  • Branding — full-bleed icons marked maskable (cropping); no on-page logo mark; no per-route metadata.

02 How it was run

The Orchestrator ran phases as isolated multi-agent workflows, integrating and running the gates between each, committing a checkpoint per phase. A session-scoped resume + a repo-committed state anchor carried the mission across a usage-limit reset mid-flight.

Phase 0 — Specify (Leon & Lisa)

A quality floor + a ~180-assertion acceptance spec, and every user-visible string + metadata in the project voice. Peer report-card round to the pass bar (both A-).

Phase 1 — Implement (Jerry ×5, Dave ×2)

Eight agents on strictly disjoint file sets (globals.css frozen) fixed all 21 components + every route: boundaries, per-route metadata, coaching-service call discipline, accessibility contracts, 44px targets, reduced-motion self-guards, tab + on-page branding, the view-transition flag.

Phase 2 — Verify & fix (Sierra + fix loop)

Six adversarial audit lenses + a gates/smoke runner filed 17 defects (0 blocker, 8 major, 9 minor) into docs/qa.md. A targeted fix loop cleared all 17; re-verified green.

Ship — deploy + verify

Pushed, deployed to production, and verified the live public domain serves the new build.
